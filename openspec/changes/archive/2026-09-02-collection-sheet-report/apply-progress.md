## Deviations from Design

- Inherit view xpath is asserted by parsing `views/collection_sheet_report_views.xml`
  from disk with lxml, not via `ir.ui.view` xmlid. Design/tasks keep `__manifest__.py`
  `data` for D; loading the inherit in A would require the contested manifest. D now
  registers that `data` path; upgrade loaded
  `collection/views/collection_sheet_report_views.xml`.
- `models/__init__.py` `from . import collection_sheet_report` was added in 1.4 with the
  model file (same PR A) rather than in 1.2, so 1.2 GREEN could load the registry before
  the inherit module existed.
- No custom `_init_column` override: `document_kind` uses Selection
  `default="invoice"` + `required=True` so Odoo 19 `_init_column` backfills existing
  rows.
- `ir.actions.report` has no `context` field in this Odoo 19 registry.
  `discard_logo_check` is passed from tests via `with_context`; it is not stored on the
  action record.
- HTML `_render_qweb_html` tests patch `ir.qweb._get_asset_nodes` to `[]` because devel
  `web.report_assets_common` still lists `website/` snippet SCSS while `website` is not
  installed. Production Print still uses `web.html_container` + `web.external_layout`.
- Company-B AccessError fixture restricts a company-A user and prints a company-B sheet
  (SQL `res.company` insert copies `fiscalyear_last_day` from the current company). ORM
  `res.company.create` hits the pre-existing NOT NULL column that is absent from this
  registry's `_fields`.
- XLSX payload still has no `currency_symbol` / `currency_decimals` keys (Phase 1
  `PAYLOAD_KEYS` is an exact set). The writer uses template number formats (`#,##0.00` /
  `"$" #,##0.00`) and never reads `payload["currency"]`.
- xlsxwriter omits default `fitToWidth=1` and converts character width 32 to
  `32.7109375`. `_align_workbook_xml` rewrites worksheet XML to the template's
  `fitToWidth="1"` and `width="32"` so openpyxl assertions match the workbook spec.
  Cached formula `<v>` cells are left untouched.
- D did not re-add `web` (already present from B). Manifest `data` appends inherit views
  after the three report XML files only.
