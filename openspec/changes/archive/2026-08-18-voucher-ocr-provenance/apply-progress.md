### Issues Found

- `invoke test -m collection` without `--mode=update` runs `-i collection` and reports **0 tests** when the module is already installed. Use `--mode=update` or `docker exec … -u collection --test-tags /collection`.
- `inspect.getsource` on the Odoo snapshot *class* raises `OSError: could not find class definition`; inspect `create`/`write`/`_unlink_forbidden` instead.
- `invoke install -m collection` stops `seedian-odoo-1` and uses `--init`; it does not reload XML on an already-installed module. Phase 2 views required `-u collection` (focused GREEN and `--mode=update`).
- Phase 3 OWL XML is cursorignored for some editor tools; filesystem writes still apply. Prettier reformats the OWL template; tests assert `t-att-value` / `t-if` source, not CSS.
