# Collections

Odoo 19 backend app for **cobranzas** payment vouchers. Operators (and agents via
MCP) register bank transfers, checks, and cash deposits, then validate or reject
them.

> `README.rst` is generated by `oca-gen-addon-readme` from `readme/` fragments.
> Edit those fragments for Apps store / OCA metadata; this `README.md` is the
> human-facing module guide.

## Features

- Payment vouchers with sequence `COL/<year>/<number>`
- Lifecycle: **New → Validated** or **New → Rejected**
- Payment lines: bank transfer, check, cash deposit, or unsupported
- Mail chatter + activities on every voucher
- MCP tool `create_collection_voucher` (MuK MCP, method-discovered)

## Models

| Model | Purpose |
| --- | --- |
| `collection.voucher` | Header: reference, customer identification, state, currency |
| `collection.voucher.line` | Payment line: document type, optional OCR-style fields, unique `document_id` |

Registration time is ORM `create_date` (readonly). There is no `received_date`.

## Backend UI

**Collections → Payment Vouchers**

- List / search: reference, customer identification, created on, status
- Form: statusbar, Validate / Reject (when New), editable payment lines, chatter

Internal users (`base.group_user`) have full CRUD. No dedicated security groups.

## MCP: create a voucher

Tool name: `create_collection_voucher`  
Auth: caller's user (never `sudo()`). ACL on voucher/line models applies.

Required input:

- `customer_identification` (non-empty string)
- `payments` (non-empty array; each item needs `document_id` + `document_type`)

Idempotency by `document_id`:

| Situation | Result |
| --- | --- |
| All `document_id`s new | Create voucher + lines |
| All map to one existing voucher | Return that voucher unchanged |
| Duplicate in one call / partial overlap / cross-voucher | Reject, no writes |

Example payload:

```json
{
  "customer_identification": "CUIT 30-12345678-9",
  "payments": [
    {
      "document_id": "ocr-doc-001",
      "document_type": "bank_transfer",
      "amount": 15000.5,
      "from_account": "0001234567",
      "to_account": "0009876543"
    }
  ]
}
```
